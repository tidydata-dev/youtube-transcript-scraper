# YouTube Transcript Scraper — Python, Node.js & cURL examples

Get the **transcript of any YouTube video** — and of **whole playlists, channels (@handle) or search results** — as clean text, timed segments, **SRT / VTT subtitles** and **chapters with their own text**. No YouTube API key, no cookies, no proxies to manage.

This repo shows how to call the hosted **[YouTube Transcript Scraper on Apify](https://apify.com/tidydata/youtube-transcript-scraper?fpr=wtg6qt)** from your code. It costs **$0.50 per 1,000 transcripts**; videos without captions are free.

## Why not just `youtube-transcript-api`?

Libraries that read captions directly work on your laptop but get **"Sign in to confirm you're not a bot"** as soon as they run on a server (AWS, GCP, Vercel, Docker…). The hosted Actor handles the blocking, retries and parsing for you and also lists **playlists, channels and searches**.

## Quick start (Python)

```bash
pip install apify-client
export APIFY_TOKEN=...   # free account at apify.com → Settings → API & Integrations
```

```python
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("tidydata/youtube-transcript-scraper").call(run_input={
    "sources": [
        "https://www.youtube.com/watch?v=iCvmsMzlF7o",   # a video
        "@lexfridman",                                     # a channel (newest first)
        "how to start a podcast",                          # a search
    ],
    "maxVideosPerSource": 5,
    "languages": ["en"],          # optional: preferred caption languages
    "includeSrt": True,
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    if item["status"] == "ok":
        print(item["title"], "-", item["wordCount"], "words")
        print(item["transcript"][:300], "…")
```

## What you get per video

| field | example |
|---|---|
| `title`, `channelName`, `durationSeconds`, `viewCount` | video metadata |
| `language`, `isAutoGenerated`, `availableLanguages` | which captions were used |
| `transcript` | readable paragraphs (or plain / `[mm:ss]` lines) |
| `segments` | `[{start, duration, text}]` in seconds |
| `chapters` | `[{title, start, end, text}]` when the video has chapters |
| `srt`, `vtt` | subtitle files as text |
| `status`, `error` | `ok`, `no_transcript`, `language_not_available`… (non-ok rows are free) |

## Inputs it accepts

`watch?v=` · `youtu.be/` · `/shorts/` · `/live/` · `/embed/` links · 11-character IDs · playlist links · channel links / `@handles` (add `/shorts` or `/streams` for those tabs) · plain search terms.
